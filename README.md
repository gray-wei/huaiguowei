# Guowei Huai Homepage

This repository publishes Guowei Huai's academic homepage at:

<https://gray-wei.github.io/huaiguowei/>

The live site is currently a small static homepage generated by Node.js scripts. It is **not** built with Jekyll in the deployment path.

## Current Setup

- `scripts/build-preview.mjs` builds the static site into `_site/`.
- `scripts/serve-preview.mjs` serves `_site/` locally.
- `tests/preview-build.test.mjs` verifies the generated homepage content and required assets.
- `.github/workflows/deploy.yml` runs `npm run test:preview` and deploys `_site/` to GitHub Pages.

## Editing Content

- `scripts/profile.mjs` contains identity, publication metadata, projects, education, and honors.
- The homepage groups arm–hand teleoperation under the mobile robotic platform, with separate module credits and a details page. The CV retains teleoperation as an independent research experience.
- `scripts/build-preview.mjs` renders the homepage and teleoperation details page.
- `assets/homepage.css` controls layout and colors; `assets/homepage.js` keeps only one demo playing at a time.
- `assets/img/research/` contains video posters. Videos have playback controls; longer demos defer loading until playback.

HiFun metadata follows [the official project page](https://hly-123.github.io/HiFun/). Add resources only when real URLs are available.

The HiFun player uses the original [Overview video](https://hly-123.github.io/HiFun/assets/media/supplementary.mp4) and its matching poster from Linyi Huang's project page. Its full video is stored locally without trimming or transcoding, with sound enabled and loading deferred until playback. Mobile platform and RDT overview players use compact previews.

The homepage leads the mobile platform's media with Guowei Huai's Vision Pro demonstration, followed by the team platform overview. The teleoperation details page shows Guowei's video first, then the full 55-second GELLO + Manus demonstration operated by Linyi Huang further down. The local GELLO original is `../gray_cv/video/Gello_Demo_Linyi.mp4`; the published copy is `assets/video/research/gello-manus-redacted.mp4`. At the source resolution of 960 × 544, the entire video has a pixelated head region at x=178, y=62, width=184, height=218. This fixed region covers the operator's head and head-mounted module throughout the clip. The poster was extracted from the redacted output. The original stays outside the site's assets and build.

The module description highlights Manus glove retargeting and the common interface that unifies Manus and Vision Pro inputs in one repository across Inspire Hand, Leap Hand, XHand, and Sharpa.

## Updating the CV Download

The English CV is maintained in the sibling `gray_cv` repository. The Chinese version stays there as a local draft and is excluded from the homepage and site build. After exporting the English PDF, synchronize the download:

```bash
npm run cv:sync -- ../gray_cv
npm run test:preview
```

The English input is validated as a PDF before replacing the homepage download. Synchronization does not copy the Chinese draft.

## Local Preview

```bash
npm run test:preview
npm run preview:serve
```

Then open:

<http://127.0.0.1:4173/>

## Deployment

Push changes to `master` on GitHub. The `Deploy site` workflow builds the static preview and publishes the generated `_site/` directory to the `gh-pages` branch.

> Note: Do not edit `gh-pages` directly. It is generated by GitHub Actions.
